# Рабочие сценарии старой системы (не изобретать велосипед)

Цель новой операционки: **привычный порядок действий**, не «другая религия».  
UI может быть в Telegram Mini App, но **шаги и поля** — как в текущей OpenCart-кассе / приходах.

Режим изучения админки: **только чтение** (формы смотрели, Save/Import не жали).

---

## 1. Импорт каталога (Export / Import)

Путь: **Модули → Export / Import** (`extension/export_import`).

| Вкладка | Что делает |
|---------|------------|
| **Export** | Выгрузка в XLSX: Categories / **Products** (+ options) / Option definitions / Attributes / Filters / Customers |
| **Import** | Загрузка XLS / XLSX / ODS |
| **Settings** | Настройки модуля |

**Import:**
- формат = тот же, что даёт Export («сначала сделай Export, чтобы видеть формат»);
- режим **incremental Yes** = обновить/добавить;
- **No** = удалить старое и залить заново (опасно — в проде не трогаем).

**Для нас:**  
- разово забираем каталог через **Export Products** (уже сделано);  
- в новой системе свой импорт/добавление;  
- чужой Import в OC **не запускаем**.

## 2. Касса — как работают сейчас

Путь: **Продажи → Касса** (`sale/sale`).

### Список
Колонки: **Номер · Тип · Дата · Доставка · Автор · Сумма · Действие**.  
Фильтры: период, склад, тип отчёта (общий / продажи / доставка / по наименованию).

### Типы операций (кнопки создания)
| Тип | `operation_type` | v1 новой системы |
|-----|------------------|------------------|
| **Продажа** | `sale` | **Обязательно** (главный сценарий продавца) |
| Возврат | `return` | Желательно заложить / 2-я очередь |
| Заработная плата | `salary` | Не в v1 сайта |
| Компенсация / Прочее / Размен / Перемещение | … | Не в v1 |

### Новая продажа — экран (сохранить логику)

1. Выбрать **склад** (у них один: пр-т Дзержинского 19).  
2. **Выбрать товар** — поле поиска + автокомплит  
   - API: `sale/sale/autocomplete&warehouse_id=…&filter_name=…`  
   - По **артикулу** находит модель (пример: `1577` → AIR JORDAN 11 BLACK).  
   - В ответе сразу **размеры с количеством > 0** и цена.  
3. **Добавить товар** в таблицу строк:  
   `Наименование | Код | Количество | Цена | Сумма`  
   + строка размера (`Размер: 39`), **«Доступно: N шт.»**.  
4. Можно править **цену** на продаже и **скидку** (сумма или %).  
5. **Доставка:** Нет / Да.  
6. **Оплата:** Наличными / Картой / Смешанная (поля cash+card).  
7. **Комментарий**.  
8. **Сохранить** → списание со склада, запись в кассу с номером.

Пример живой продажи №22824: AF1 07 WHITE, размер 39, цена 145, скидка 5 → **140**, автор admin2.

**Заказы сайта** (`sale/order`) сейчас пустые — сайт-заказы у них по сути не через этот список; касса = офлайн/ручные продажи.  
В новой системе: сайт-заказ → TG уведомление + статусный поток; **продажа в зале** = этот кассовый сценарий.

## 3. Приходы + бирки (уже привычно)

**Приходы товаров** (`catalog/product_arrival`):  
список `Дата · Товар · Размер · Склад · Кол-во · Распечатан`.

Сценарий: добавили размеры → строки прихода → **печать наклеек** → статус «распечатан».

В новой системе повторить смысл:
`новый товар/привоз → размеры/кол-во → печать этикеток → учёт распечатки`.

## 4. Склад (отчёт)

**Отчеты → Товары на складах:** один склад, агрегаты по категориям  
(напр. мужские/женские кроссовки — штуки).  
В v1 достаточно: остатки по модели+размеру + простой итог; категории «муж/жен» — если понадобится фильтр позже.

## 5. Принцип для Mini App (чтобы не переучивать)

| Роль | Как в старой системе | Как делаем |
|------|----------------------|------------|
| Продавец | Касса → Продажа → артикул → размер → цена/скидка/коммент → сохранить | Тот же поток, без редактирования каталога |
| Админ | Товары + приходы + печать + касса | Всё то же + сайт-заказы/статусы |
| Поиск | Артикул / название через автокомпилт склада | Артикул вручную + сканер (пикалка) |
| Наличие | Видно «Доступно: N» при выборе размера | То же |
| Цена на чеке | Можно менять + скидка + коммент | То же (как просили в ТЗ) |

**Не делать:** другой порядок кнопок «с нуля», прятать артикул, убирать скидку/коммент с продажи, заставлять оформлять зал только как «сайт-заказ».

## 6. Что сознательно НЕ копируем в v1

- Зарплата / размен / перемещение / компенсация в кассе  
- Полный OC Export/Import как ежедневный инструмент  
- История клиентов/старых website orders (пустые / не переносим)  
- Кривые названия брендов в OC — можно поправить при импорте
