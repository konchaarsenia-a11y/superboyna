# Wellsneakers Shop — ТЗ (закреплено)

Клиентский сайт кроссовок + операционка в Telegram.  
Демка UI: [`wellsneakers-room/`](../wellsneakers-room/) (стиль утверждён).  
Срок v1: **~25 дней** с старта разработки.

**Статусы:** `[x]` сделано · `[~]` частично · `[ ]` не сделано

---

## 1. Продукт одной фразой

Витрина на том же домене/бренде: каталог кроссовок с живым наличием по размерам → заказ без онлайн-оплаты.  
Оперативка в Telegram Mini App: склад, привоз, продажа, бирки/штрихкод, статусы заказов.

---

## 2. Стек (утверждён)

| Слой | Технология |
|------|------------|
| Сайт клиента | HTML / CSS / JS (база UI — `wellsneakers-room`) |
| Mini App сотрудников | HTML / CSS / JS + Telegram WebApp SDK |
| API | Node.js + Express |
| БД | PostgreSQL |
| Бот (уведомления) | GrammY |
| Хостинг | VPS в Беларуси + Docker + nginx |
| Оплата v1 | нет (при получении) |

Один сервер, два входа: сайт и Telegram → один API → одна БД.

---

## 3. Домен и бренд

| Решение | Деталь |
|---------|--------|
| Домен | Оставляем текущий (**hoster.by**, доступ есть) |
| DNS | Направить на наш BY VPS |
| Название / бренд | Сохраняем |
| SEO / 301 | Ссылки в основном на главную в соцсетях; точечных URL мало → минимум редиректов |
| Старые клиенты/заказы | **Не** переносим |

## 5. Операционка (Telegram Mini App) — ответы

### Роли

| Роль | Права |
|------|--------|
| **Продавец** | Отбить продажу, смотреть наличие. **Нельзя** редактировать товары/цены/остатки |
| **Админ** | Всё: товары, цены, остатки, удаление, привоз, инвентаризация, статусы |

Редактирования каталога/склада — только админ (заказчик).

### Заказы

| Тема | Решение |
|------|---------|
| Уведомление | Сообщение в Telegram при новом заказе с сайта |
| Статусы | **В обработке** → **В пути** → **Выдан** |
| Отмена | Заложить в v1 (возврат остатка); уточнить подпись в UI при необходимости |
| Продажа в зале | Списание; можно **менять цену** и **комментарий** на эту продажу |

### Склад

| Тема | Решение |
|------|---------|
| Учёт | Модель + размер + количество (пример: белые Force 41×2, 43×1) |
| Размер с 0 | Не показывать |
| Привоз | Вручную: товар, цена, размеры, фото → сразу печать этикеток |
| Списание | С продажи / заказа; плюс инвентаризация |
| Инвентаризация | **Да** (сверка факта с системой) |
| Алерты «мало на складе» | **Нет** |

### Бирки и штрихкод

| Тема | Решение |
|------|---------|
| Шаблон | Один на все; меняются название, размер, артикул |
| Образец | Клиент пришлёт фото своей бирки |
| Штрихкод | Генерируем с сайта/системы **на модель** (уточнить: один код на модель или model+size) |
| Принтер | Термо ~**58×58** (клиент уточнит) |
| Скан | Пикалка + **обязательно ручной ввод артикула** |
| Назначение скана | Продажа / поиск позиции по артикулу |
