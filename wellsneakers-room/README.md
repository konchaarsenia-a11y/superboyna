# wellsneakers — вариант «комната»

Витрина только кроссовок (без одежды). Позже этот UI поедет на боевой домен.

- Главная: лого + «кроссовки в Минске» + CTA в каталог; Ему / Ей; три чипа преимуществ раскрываются по тапу
- Каталог: `catalog.html` — кому / скидки / бренд / размер, пустое состояние, корзина
- Низ: липкая кнопка «В каталог»
