# Варок — партнёрское приложение (заказы пополнения)

Telegram Mini App для **владельцев точек Варок**: заказ лакомств и купонов у Бойни.

**Не путать** с:
| | Что |
|---|---|
| Конвейер `app.html` | Команда Бойни (заказ/нарезка/курьер) |
| Goodboy | Клиенты-собачники (скидка в Варок) |
| Лист «Партнёры» | Источник БП («кто привёл»), не точки Варок |

---

## Роли

| Роль | Кто | Может |
|------|-----|--------|
| **Владелец точки** | Менеджер/владелец кофейни | Видит только свои точки → заказывает лакомства и купоны |
| **Админ каталога** | Владелец Бойни (или сеть Варок) | Кабинет: каталог позиций, точки, доступы |

Вход только через Telegram (`initData` / `telegramId`). Без привязки к точке — экран «нет доступа».

---

## Поток (MVP)

```
Открыл Mini App
  → auth по telegramId
  → список МОИХ точек (допуск только owner точки)
  → выбрал точку
  → каталог: Лакомства | Купоны
  → кол-во → корзина → «Отправить заказ»
  → заказ в лист VR_Заказы + (опц.) уведомление Бойне
```

Если у человека **одна** точка — сразу в каталог (точку можно сменить).

### Кабинет админа

- Вкл/выкл позиции в каталоге, цена, название, тип (`treat` / `coupon`)
- CRUD точек (название, адрес)
- Привязка telegramId → точка(и) (роль owner)
- Просмотр входящих заказов (статус: new / accepted / done)

---

## Экраны

1. **Точки** — список доступных; тап = выбор  
2. **Заказ** — табы Лакомства / Купоны; степпер qty; низ: корзина + итог + «Отправить»  
3. **Мои заказы** — история по выбранной точке  
4. **Кабинет** (только admin) — Каталог / Точки / Доступы / Заказы  

---

## Данные (листы Google Sheets)

Префикс `VR_` — не смешивать с конвейером.

| Лист | Колонки |
|------|---------|
| `VR_Точки` | `id`, `name`, `address`, `active`, `createdAt`, `updatedAt` |
| `VR_Доступы` | `telegramId`, `name`, `username`, `locationIds` (csv), `role` (`owner`\|`admin`), `status`, `createdAt` |
| `VR_Каталог` | `id`, `type` (`treat`\|`coupon`), `name`, `unit`, `price`, `active`, `sort`, `updatedAt` |
| `VR_Заказы` | `id`, `dateIso`, `locationId`, `locationName`, `telegramId`, `userName`, `basketJson`, `total`, `status`, `note`, `createdAt` |

`basketJson`: `[{id, type, name, qty, price, unit}]`.  
Владелец Бойни (`isOwnerId_`) всегда = `admin` без строки в `VR_Доступы`.

## API (префикс `vr*`)

| Action | Кто | Назначение |
|--------|-----|------------|
| `vrMe` | любой | роль, имя, список моих точек |
| `vrGetCatalog` | owner/admin | активный каталог (admin: `all=1` → все) |
| `vrSubmitOrder` | owner точки | создать заказ |
| `vrListOrders` | owner / admin | мои / все заказы |
| `vrAdminSaveCatalog` | admin | upsert позиции |
| `vrAdminSaveLocation` | admin | upsert точки |
| `vrAdminSaveAccess` | admin | upsert доступа |
| `vrSetupSheets` | owner Бойни | создать листы + сид каталога |

Фронт: `varok/app.html` (Pages: `/varok/`).  
Бэкенд: тот же webhook `Code.gs`, actions `vr*`.

---

## Решения (зафиксировано для старта)

1. Каталог правит **админ Бойни**, не каждая точка.  
2. Заказ = заявка на пополнение; в конвейер «Прием заказов» **пока не пишем** (отдельный лист; связка позже).  
3. Купоны — отдельный тип в каталоге (пачка = 1 позиция с ценой пачки).  
4. Один telegramId может владеть **несколькими** точками.  
5. Бариста без доступа — не входит (только owner точки).  

Можно поправить после первого прогона с владельцем.
