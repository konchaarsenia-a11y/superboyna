## Почему calcPrice не читает лист

Цепочка D1 (`boinya-c/proxy/worker.js`):

1. `calcPricePpD1_` **31466–31499** → snap `priceCostsPp`
2. `costsForCalcD1_` **31118–31122** → `loadRawCostVersions_` + `overlayRawCostsD1_` **31078**
3. `raw_cost_ver` пуст → overlay ничего не красит
4. `lookupPpCostInfoD1_` **31162** → snap / `RAW_COST_BUILTIN_` **3934**

Не читает: Google «Подписка», таблицу `raw_costs` (только stage-C зеркало, `stageCNoteRaw_` **37224**).

Сохранение из Mini App: `retail-admin.js` `saveCost` → `saveRawCost_` **4098** → INSERT только в `raw_cost_ver`. Раз версий 0 — через «Внести» в карточке после 09.10 **успешно не сохранялось** (или таблицу чистили). Правки ушли в Sheets вручную.
