## Dual-scheme (важно)

| | LEGACY (старые) | RAW26 (новые с **2026-08-31**) |
|--|--|--|
| Формула | `сырьё×coef + 11 + 6×N + пакеты` | `сырьё×M + recover + 9×N + пакеты` |
| M / coef по умолч. | 2.3 | **2.6** |
| Тег в wishes | нет / `[SCHEME:LEGACY]` | `[SCHEME:RAW26]` + `[COEF:2.6]` |
| Указанная цена на листе ПП | **не трогаем** автоматом | ставится при зачислении / migrate |
| Календарь доставок | без изменений | без изменений (migrate тоже не трогает) |

Ручной перевод старого ПП: кнопка в карточке → action `migratePpToRaw26Scheme`.

Сырьё `cost_new` залито оверрайдом в `Code.gs` (`PP_RAW_COST_OVERRIDE_BYN_`); желательно продублировать на лист прайса «Подписка».

## 0. Философия

1. **Зарабатывать только на сырье** — накрутка `M` только на `Σ(сырьё)`.
2. **Свет / нарезка / дойпак** — в цену **по себесу** (×1), без прибыли.
3. **Жевалки шт** — в сушилке почти не занимают место, режутся быстро → recover **мягкий** (`+0,50`), не `+2,40`.
4. **ПП < розница** по товарной части (потолок 92% Σ розницы строк).
5. Пакеты/крафт УП4 — фулфилмент **плюсом**, без наценки.

Раньше (ошибочно для твоей логики): накрутка на полный COGS → ты ещё «зарабатывал» 35% на свете и ЗП.

## 1. Формула новых ПП

```
recover_100г = 3,90          # свет+нарезка+дойпак — только возмещение
recover_шт   = 0,50          # жевалка: доля пака + чуть труда (не 2,40)

товар = Σ(сырьё)×M + Σ(recover)
товар = min(товар, Σ(розница)×0,92)
фулфилмент = 9×N + пакеты    # У* / УП4 крафт
цена = товар + фулфилмент

вклад = Σ(сырьё)×(M−1) + (9−7)×N
# recover и пакеты в нуле; с доставки +2 за шт доставки
```

| Параметр | Значение |
|----------|----------|
| **M на сырьё** | **2.60** база для новых (RAW26) |
| recover 100г | **3.90** |
| recover жевалка шт | **0.50** |
| F | **9** × N |
| Пакеты | pass-through |
| Старые ПП | без изменений `×2,3 + 11 + 6×N + пакеты` до ручного migrate |

### Жевалки

Старое `+2,40` на шт размазывало ЗП/свет как на 100г дрессуры — **криво** для корня/трахеи/уха.
Рабочая норма **0,50** (пак ~0,40 + чуть рук). Если по факту цеха мало — можно **0,30–0,40**.

Цена клиенту при M=2,5 и recover жевалок 0,50 ≈ **136** (всё ещё далеко до розницы 196).

## 4. Вердикт

- База новых: **M=2.60 только на сырьё**, recover 100г=3.9, жевалка=0.5.
- Вклад ≈ `сырьё×(M−1) + 2×N` — прозрачно.
- Старые карточки и уже внесённые доставки не пересчитываются; перевод — вручную.
- Жевалки: не раздувать recover — иначе цена растёт без роста заработка на сырье.
