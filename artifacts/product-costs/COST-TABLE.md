# Себестоимости Бойня C — рабочая таблица (2026-08-25)

Handoff для агента. **Не заливать в прайс без явного ОК владельца.**

Источник расчёта: закуп (BYN/кг) + выход сушёного (г/кг или шт/кг).  
Строка в [прайс-таблице](https://docs.google.com/spreadsheets/d/1c3iETyh_eOGcL0_zsGapzliVEfhQk5fQqbg8aAGAgI0): **«Себестоимость 100г»** (листы Подписка / БП).

## Формулы

```
себест 100г  = закуп_кг × 100 / выход_г_с_кг
себест шт    = закуп_кг / шт_в_кг          (или вес_сырья_кг × закуп)
сырое кг     = сухие_гр / 1000 / D         (лист Склад, кол. D)
факт ПП      = сырая_себест × coef + 11 + 6×N + пакеты + наценка_фракций
coef         = 2.3 (по умолчанию)
пакеты       = У1 0.34 · У2 0.56 · У3 0.80 · УП4 1.40 BYN
```

## Для агента: куда заливать

1. **Прайс-таблица** — строка «Себестоимость 100г», листы **Подписка** и **БП** (одинаковые значения).
2. **Code.gs** — `readPriceCosts_()` читает оттуда; hardcode не нужен, кроме `RETAIL_PRICE_BYN_` (розница).
3. **Не трогать** позиции из блока «Вне прайса» — убрать/обнулить при заливке.
4. **Deploy Code.gs** — после правок в Script; сброс кэша `PRICE_COSTS_MEM_` при деплое автоматически.
5. **Приложение (`app.html`, `boinya-c/`)** — по указанию владельца другой агент; эта таблица только себест.
