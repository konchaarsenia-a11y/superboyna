# Канон расчёта 09.10.2026

Утвердил владелец 09.10.2026. Это актуальная схема. Старые документы остаются как история: в них в шапке стоит ссылка сюда.

Код считает новые расчёты, внос, экономику и статистику по этой схеме. Груши в таблице кода 6,60. Сохранённые карточки не переписываются. Себес и пустая усушка правятся в прайсе мини-аппа, версия с датой лежит в D1.

Розничные цены позиций в примерах взяты из текущего `RETAIL_PRICE_BYN_` в `Code.gs` (прайс витрины). Промежуточные суммы до копейки (`Math.round` до 0,01). Клиенту цена подписки округляется до рубля (`Math.round`).

## 1. Подписка

```
Цена = min(сырьё×M + recover + доставка×N + фракции + пакеты;  0,92×R)
```

Клиенту эта цена округляется до рубля.

| | |
|---|---|
| M | по умолчанию **2,6** |
| R | розница состава по прайсу позиций плюс розничная доставка, если товар на одну доставку ниже 80 |
| Потолок | 0,92×R на всю цену |

**Recover в подписке**, без упаковки:

|---|---:|---:|
| Нарезчик | 2,50 | 0,50 |
| Свет | 0,80 | 0,30 |
| **Итого** | **3,30** | **0,80** |

**Доставка в подписке, 7,60 за одну:**

| | BYN |
|---|---:|
| Бензин | 4,00 |
| Сборщик | 3,00 |
| В чистое | 0,60 |
| **Итого** | **7,60** |

Крафт-пакет 1,40 в эту доставку не входит.

**Пакеты отдельными счётчиками:**

| | BYN |
|---|---:|
| у1 | 0,34 |

## 6. Статистика и экономика

Один путь себеса подписки:

```
Себес = сырьё + 3,30×(граммы/100) + 0,80×штуки + 7,60×N + пакеты по счётчикам
```

Фракции и множитель M в себес не входят: это наценка, не закуп.

Чистое считается от указанной стоимости:

```
Чистое = указанная − себес
```

Фактическая цена формулы для чистого не берётся.

Экономика показывает колонками:

- себес каждой позиции
- общий себес сырья
- recover подробно (нарезчик и свет, граммы и штуки)
- доставку: бензин 4, сборщик 3, 0,60 в чистое
- пакеты по счётчикам
- фактическую стоимость
- указанную стоимость
- чистое

## 7. Редактируемый себес

В прайсе мини-аппа (роль владелец) у каждой позиции есть себес, усушка и дата действия. Версии лежат в D1 `raw_cost_ver`. Расчёт, оффер ПП, экономика, статистика и внос берут себес, действующий на дату записи или доставки. Старые записи не переписываются.

Усушка в коде и таблицах отдельным числом на позицию не хранилась. Поле есть, по умолчанию пустое. В формулу цены оно не входит. На складе другой коэффициент: сухое делят на него, чтобы получить сырьё. Это не это поле.

Кролика в таблице нет: себес пустой, владелец вписывает сам.

## 9. ПП2, оплата за месяц

Клиент платит за месяц один раз: в 1-ю или во 2-ю доставку.

Оплачено в 1-ю: во 2-й сумма не показывается, в оборот не входит, курьеру вопрос «оплачено?» не задаётся.

Не оплачено в 1-ю: во 2-й сумма показывается, курьер отмечает оплату, в оборот входит один раз.

N=1: второй доставки нет, правило слота 2 не применяется.

## 10. Себес, выход и розница (пачка 10.10.2026)

Складской коэффициент — это **выход**, доля, которая остаётся после усушки. Не процент потерь.

```
сырьё_кг = сухое_г / 1000 / выход
```

База на складе — **0.2**. В прайсе то же число: поле «Выход (коэф склада)», допустимо (0; 1].

Смена только выхода пересчитывает себес сразу, со дня версии:

```
себес_новый = себес_старый × (выход_старый / выход_новый)
```

Если в той же версии вписан и себес, и выход — себес уже за 100 г готового при новом выходе, второй раз не умножается. Старый выход, если в версии его ещё не было, берётся с коэффициента склада, иначе 0.2.

Экономика и статистика читают новый себес с даты версии. Сохранённые карточки и уже внесённые заказы не пересчитываются.

Розница клиенту от этого не меняется. Кнопка «Обновить прайс» один раз масштабирует сохранённый прайс (`retailPrices`) от базиса `costBasis`. Первый раз базис — канон себеса, если базиса ещё нет. Карточки не трогаются.

При запуске мини-аппа `getRetailPriceList` → `applyRetailPriceMapToUi_`. Новые заказы, расчёт розницы и потолок подписки идут по этому прайсу.

Склад и нарезка на дату берут выход из версии себеса (`yieldMapForDate`). Нет версии — остаётся коэффициент листа.
