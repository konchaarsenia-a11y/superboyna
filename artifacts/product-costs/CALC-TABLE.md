# Расчётная таблица себестоимости

Собрано в одну таблицу для расчёта в чате.

- **cost_now** — текущая себест. из прайса (ПП/БП), BYN за ед.
- **coef** — коэф усушки со Склада (доля сухого от сырого). Для жевалок `1 (шт)` = учёт штуками, не усушка.
- **buy** — цена из сообщения поставщика, BYN/кг сырого.
- **formula_hint** — только арифметика `(0,1 ÷ coef) × buy` для 100 г; **это не новая себестоимость**.
- **new_cost** — пусто: заполняешь ты.
