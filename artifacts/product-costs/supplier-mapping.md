# Сопоставление: прайс поставщика → наш ассортимент

Рабочая таблица для расчёта: **[CALC-TABLE.md](./CALC-TABLE.md)** (+ `calc-table.csv`).

Закупка поставщика: **BYN/кг** (сырое).  
Себестоимость в мини-аппе: **BYN за 100 г сухого** (дрессура) или **BYN за шт** (жевалки).

Формула для граммовых (сухое) — только подсказка, не «новая цена»:  
`себест_100г ≈ (0,1 ÷ коэф_усушки_склад) × закуп_BYN/кг`

Коэф склада = доля сухого от сырого (Склад!D). Пример: коэф 0,20 → из 1 кг сырого ≈ 200 г сухого → 100 г сухого ≈ `закуп/2`.

Новые себестоимости заполняет владелец в колонке **Новая** в CALC-TABLE — агент их не знает.

## Не используем из прайса поставщика

Язык (если не пикальное), свинина, телятина, обрези говяжьи, фарши, сычуг, дружок, микс, калтык, селезёнка, рёберный хрящ, хвосты, сустав, куры/цыплята, бараний рубец, бараньи почки и др.

## Нет в прайсе поставщика

КОПЫТО, БАРАНЬЕ ЛЁГКОЕ (явно), овощи/фрукты (бананы, яблоки, морковь…), КРОШКА СЕРДЦА / МИКС (если продаём).
