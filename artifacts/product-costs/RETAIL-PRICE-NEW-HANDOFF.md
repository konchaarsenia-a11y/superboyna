# Розничный прайс — NEW (витрина) · handoff для агента

Дата: 2026-08-30  
Статус: **согласован с владельцем** · залит в `RETAIL_PRICE_BYN_` / `RETAIL_PRICE` (Pages `v71115913`) · доставка `<80 → 9` · **нужен Deploy Code.gs** для GAS `calcPrice`.  
Уже сохранённые `orderPrice` / доставки **не пересчитываются**.  
Источник: этот handoff + `RETAIL-PRICE-NEW.json` / `.csv`.

## Задача агенту

Заменить розничные цены в приложении на значения из **`retail_new`** ниже:

1. `Code.gs` → объект `RETAIL_PRICE_BYN_`
2. `boinya-c/app.main.js` → объект `RETAIL_PRICE` (зеркало для локального calc)
3. При необходимости — лист прайса «Розница» в PRICE spreadsheet  
4. Доставка розницы: сейчас в коде `<50 → 5 BYN`; целевое: **`<80 → 9`, от 80 → 0`** (см. ADULT-COST-MODEL)
5. **Не трогать** цены уже внесённых доставок / старых ПП / `factCost` на листе ПП
6. Убрать с витрины (не продавать / не показывать в рознице): см. блок «Убрано»

Ключ в коде: `"NAME|Sub"` или `"NAME"`; жевалки — `perPiece`, граммы — `per100`, крошки — `packs` или `per100` на пак.
