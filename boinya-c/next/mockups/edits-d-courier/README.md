# Макеты вкладки Курьер

Статичные экраны 390×844. Код приложения, `Code.gs` и воркер не менялись. Имена, телефоны и адреса выдуманы.

Открыть: [`index.html`](index.html). Снять PNG: `node render.mjs`.

A — тёмная тема. B — светлая.

## v1 Крупный ник

Ник и кличка сверху, цена крупно справа. Тип цветной меткой. Адрес своей строкой, рядом «Карта». Телефон — кнопка. Состав списком, фракции микса — отдельные чипы с граммами. Статусы: не собран, собран, доставлен.

## v2 Фракции строками

Тот же верх. Состав — строки: товар и граммы по краям, фракции микса отдельными строками под чертой, не одной кашей.

## v3 Список

Четыре карточки на одном экране: ПП, БП, розница, партнёр. У каждой ник, тип, цена, адрес, карта, телефон и чипы состава с граммами. Статус на карточке.
