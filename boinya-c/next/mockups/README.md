# Макеты экранов Бойни

Статичные экраны, 390×844. Код приложения не менялся.

Открыть все сразу: [`index.html`](index.html).

Три варианта, одни и те же пять экранов:

| | Вариант | Экраны |
|---|---|---|
| A | Тёмный наш. Фон `#0d0d0f`, карточка `#16161a`, оранжевый `#ff6b1a` только у главного действия. Цифры Unbounded, текст Onest. Серый и рамки по контрасту из аудита. | Новый, Месяц, Маршрут, Клиенты, Склад |
| B | Светлый наш. Та же сетка, палитра `data-scheme=light`: крем `#f4f1ec`, акцент `#c2410c`, белый текст на кнопке. | те же |
| C | Карточный. Тёмный тон, крупные плитки, больше воздуха, нижняя панель с иконками. | те же |

Календарь месяца: на дне число людей крупно (ноль не рисуется), сверху число месяца, точки ПП / БП / розница / партнёр. Под сеткой итог выбранного дня и «N дн. с записями · всего N чел.». На маршруте плашка «собран» / «не собран», у сданной точки — «сдано».

Имена, телефоны и адреса выдуманы.
