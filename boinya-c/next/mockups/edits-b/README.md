## 18. Полоса прогресса под временем нарезки

Под таймером полоса в виде `.nx-bar`. Отметки на позициях совпадают с процентом.

Вес позиции: граммы сухого для граммовых, штуки для штучных.

Формула v1 и v2, её нужно подтвердить:

- «Выложено» даёт половину веса позиции, «Нарезано» — весь вес;
- если есть и граммы, и штуки: `(сделанные граммы / все граммы + сделанные штуки / все штуки) / 2`;
- если есть только одно — процент по нему.

Пример середины v2: 1 240 из 2 000 г это 62%, 14 из 20 шт это 70%, общая полоса (62 + 70) / 2 = 66%. В запросе рядом с этой строкой стояло «62%»: по формуле это средняя, не процент одних граммов.

v3 — те же галочки, что на экране 45%, но «Выложено» в процент не входит, считается только «Нарезано»: 600 из 2 000 г и 0 из 20 шт, полоса 15%.
