Прод-миниапп не трогаем.

---

## Шаг 0. Node.js (если ещё нет)

1. Открой https://nodejs.org/  
2. Нажми большую кнопку **LTS** (Download)  
3. Установи: везде **Next** / **Далее**  
4. Закрой и снова открой терминал (или PowerShell / «Командная строка»)

Проверка: введи `node -v` → должен показать номер версии (например `v22…`).

---

## Шаг 1. Скачать код (если ещё нет папки проекта)

### Вариант А — уже есть папка `superboyna` на диске

Открой её в проводнике. Дальше шаг 2.

### Вариант Б — нет папки

1. Открой https://github.com/konchaarsenia-a11y/superboyna  
2. Зелёная кнопка **Code** → **Download ZIP**  
3. Распакуй ZIP куда удобно (например Документы)  
4. Зайди внутрь папки `superboyna-main` (или `superboyna`)

Чтобы был прописан твой D1 ID — нужен merge PR #21  
https://github.com/konchaarsenia-a11y/superboyna/pull/21  
(**Merge pull request** → **Confirm**), потом заново Download ZIP  
**или** скажи агенту — пришлём готовый `wrangler.toml` текстом.

---

## Шаг 2. Открыть терминал в нужной папке

### Windows

1. Открой папку `superboyna` (или `superboyna-main`)  
2. Зайди в `boinya-c` → `proxy`  
3. В адресной строке проводника кликни, сотри путь, напиши `cmd` → Enter  

Должна открыться чёрная/синяя консоль. Внизу путь должен заканчиваться на `\boinya-c\proxy`.

### Mac

1. Открой **Терминал**  
2. Перетащи папку `proxy` в окно терминала после слова `cd` (с пробелом):  
   `cd ` + перетащил папку → Enter

---

## Шаг 3. Войти в Cloudflare из терминала

В той же консоли (папка `proxy`) по очереди:

```text
npx wrangler login
```

1. Нажми Enter (если спросит установить пакет — **y** → Enter)  
2. Откроется браузер Cloudflare  
3. Нажми **Allow** / **Разрешить**  
4. Вернись в терминал — должно быть что-то вроде Successfully logged in

---

## Шаг 4. Создать таблицы в D1

Всё ещё в папке `proxy`:

```text
npx wrangler d1 execute boinya-c --remote --file=./schema.sql
```

Enter.  
Если спросит подтверждение — **y** → Enter.  
Ошибок быть не должно (или «already exists» — тоже ок).

---

## Шаг 5. Задеплоить Worker

```text
npx wrangler deploy
```

Enter. Подожди 10–60 секунд.

В конце будет строка **Published** и ссылка вида:

```text
https://boinya-c.XXXX.workers.dev
```

**Скопируй эту ссылку целиком и пришли агенту в чат.**

---

## Шаг 6. Быстрая проверка

1. Открой ссылку `https://boinya-c.XXXX.workers.dev/` в браузере  
2. Должен быть JSON с `"service":"boinya-c"` и желательно `"d1":true`  
3. Если ошибка 404/error — пришли текст/скрин

---

## Если что-то пошло не так

| Сообщение | Что делать |
|-----------|------------|
| `node` не найден | Шаг 0, перезапустить терминал |
| `Not logged in` | Снова `npx wrangler login` |
| `Couldn't find DB` | Имя базы должно быть `boinya-c`; ID в `wrangler.toml` |
| Нет папки `proxy` | Ты не в той папке — шаг 2 |
| Просит merge / старый toml | Смержи PR #21 и заново скачай ZIP |

Агенту после шага 5 нужен **только URL** `*.workers.dev`.
