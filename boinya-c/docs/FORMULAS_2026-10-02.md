Актуальный канон: [PRICING-2026-10-09.md](../../artifacts/product-costs/PRICING-2026-10-09.md)

Версия: 2026-10-02 · BYN · ЗП сдельная · в подписке пакеты отдельной строкой не считаются · состав подписки = набор на месяц на N доставок

---

## 1. Обозначения

| | Что это |
|---|---|
| `S` | сырьё заказа, BYN |
| `G` | граммы весового товара (дрессура, мясо, овощи, фрукты) |
| `P` | штуки (жевалки, паки крошки) |
| `N` | число доставок |
| `R` | стоимость товара по розничному прайсу |
| `F` | доплата за фракцию (только подписка, только дрессура) |

---

## 2. Сырьё

```
сырьё_100г = закуп_за_кг × 100 / выход_сухого_г_с_кг
сырьё_шт   = закуп_за_кг / штук_с_кг
S = Σ сырьё_100г × граммы/100 + Σ сырьё_шт × штуки
```

|---|---:|
| Лёгкое | 2,25 / 100 г |
| Сердце | 4,00 / 100 г |
| Корень средний | 1,91 / шт |
| Трахея средняя | 0,88 / шт |


## 4. ЗП нарезчика-сборщика

```
ЗП = 2,50 × G/100 + 0,50 × P + 3,00 × N
```

За месяц — та же формула по суммам всех доставок месяца:

```
ЗП_мес = 2,50 × ΣG/100 + 0,50 × ΣP + 3,00 × ΣN
```

---

## 5. Розница

```
Цена     = R + Доставка
Доставка = 9 × N, если R/N < 80;  иначе 0
Маржа    = Цена − Себес
```

---

## 6. Подписка

```
Товар_raw = S × 2,6 + 3,90 × G/100 + 0,50 × P
R         = розница состава + розничная доставка
            розничная доставка = 9 × N, если R_товара / N < 80; иначе 0
            это то же число, что в тексте «в розницу выходит»
Цена      = min(Товар_raw + 9 × N + F + пакеты, 0,92 × R)
Маржа     = Цена − Себес
```

Отдельного потолка на товар больше нет. Доставка 9×N, фракция и пакеты остаются в разложении, но итог не поднимается выше 92% показанной розницы. Если розница состава 0, потолок не применяется. Уже сохранённые карточки этим правилом сами не переписываются.

Фракция (дрессура, за 100 г): целое 0 · крупное 1 · среднее 2 · мелкое 3

```
F = Σ ставка × граммы_дрессуры/100
```

Маржа подписки одной строкой:

```
Маржа = 1,6 × S − 0,40 × P + 0,60 × N + F − скидка_потолка
скидка_потолка = (Товар_raw + 9 × N + F + пакеты) − 0,92 × R, если больше 0; иначе 0
```

Откуда каждое слагаемое:

| Слагаемое | Почему |
|---|---|
| `+1,6 × S` | наценка на сырьё (×2,6 − 1) |
| `−0,40 × P` | жевалка в цене 0,50, себес 0,90 |
| `+0,60 × N` | доставка в цене 9, себес 8,40 |
| `+F` | доплата за фракцию |
| `−скидка_потолка` | вся цена урезана до 92% показанной розницы |

Старые подписки (LEGACY): `Цена = S × 2,3 + 11 + 6 × N + пакеты + F`, себес — по §3.

## 7. Месяц

```
Выручка = Σ подписок (1 раз на клиента) + Σ розницы

Сырьё_мес     = Σ S
ЗП_мес        = 2,50 × ΣG/100 + 0,50 × ΣP + 3,00 × ΣN
Свет_мес      = 0,80 × ΣG/100 + 0,30 × ΣP
Упаковка_мес  = 0,60 × ΣG/100 + 0,10 × ΣP + 1,40 × ΣN
Дорога_мес    = 4,00 × ΣN

Валовая маржа = Выручка − Сырьё_мес − ЗП_мес − Свет_мес − Упаковка_мес − Дорога_мес

Прибыль = Валовая маржа
        − Аренда 900
        − (счёт за свет − Свет_мес)
        − (закупка пакетов − Упаковка_мес)
        − Амортизация
        − SMM
        − Прочее
```

### 8.4 Подписка — 200 г лёгкого среднего, 1 доставка

### 8.6 Месяц (пример)

Допустим, за месяц: 300 доставок, ΣG = 90 000 г, ΣP = 1 200 шт, Σ S = 4 500, выручка 18 000, счёт за свет 1 100, закупка пакетов 1 050.

```
ЗП_мес       = 2,50 × 900 + 0,50 × 1 200 + 3,00 × 300 = 2 250 + 600 + 900 = 3 750
Свет_мес     = 0,80 × 900 + 0,30 × 1 200 = 720 + 360 = 1 080
Упаковка_мес = 0,60 × 900 + 0,10 × 1 200 + 1,40 × 300 = 540 + 120 + 420 = 1 080
Дорога_мес   = 4,00 × 300 = 1 200

Валовая маржа = 18 000 − 4 500 − 3 750 − 1 080 − 1 080 − 1 200 = 6 390

Прибыль = 6 390 − 900 − (1 100 − 1 080) − (1 050 − 1 080) − 150 − 800 − 100
        = 6 390 − 900 − 20 + 30 − 150 − 800 − 100 = 4 450
```
