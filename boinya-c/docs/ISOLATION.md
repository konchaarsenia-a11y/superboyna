# Изоляция от прода

## Жёсткие правила

1. Агент и люди **не правят** из задач C:
   - `/app.html`, `/Code.gs`, `/index.html` (прод)
   - `/fast/**` (уже существующая быстрая копия)
   - webhook URL в проде, лист живых заказов без явного ОК
2. Весь код C — только `boinya-c/**`.
3. Тестовый клиент в демо: `zzz_test_c` (не путать с `zzz_test` прода).
4. GAS/Sheets **не вызываем на запись** из песочницы, пока нет отдельного mirror-action и явного «можно».
5. Когда C готов к переносу: отдельный план cutover (URL бота → новая оболочка), не «влить в app.html по дороге».

## Как выглядит cutover (будущее)

1. D1 держит правду недели.
2. Mirror в Sheets — опциональный фон.
3. В боте меняется URL Mini App на `.../boinya-c/` (или переименованный путь).
4. Старый `app.html` остаётся rollback на неделю.
